# Security Policy

This repository contains only documentation (Sphinx/reStructuredText
source for the GEOS-Chem on cloud computing platforms user guide) — there
is no application source code, so there are no software releases or
version branches to track for security purposes.

## Reporting a Vulnerability

If you discover a security issue related to this documentation — for
example, a recommended AWS/GCP configuration, IAM policy, security
group setting, or example command that could expose infrastructure or
data to unnecessary risk — please report it privately rather than
opening a public GitHub issue, so that users aren't put at risk before
a fix is published.

You can report a vulnerability privately using GitHub's
[private vulnerability reporting](https://github.com/geoschem/geos-chem-cloud/security/advisories/new)
feature for this repository.

For all other bugs, typos, and non-security issues, please use the
process described in [SUPPORT.md](SUPPORT.md).
